# M0–M1 Implementation Notes

This repository currently supports a local-fixture-only prototype profile.

## Task manifest v1

The example task uses schema version `1.0`. A task must declare a source, authorization metadata, a workspace relative to the trusted workspace root, an execution profile, and one argv-based command.

## Scope policy

The current policy intentionally allows only:
- `source.kind = local_fixture`
- `authorization.status = approved`
- `authorization.scope = local_fixture_only`
- `execution_profile = offline_readonly`

This is a prototype policy, not a general authorization verification system. Do not use it to approve external targets.

## CI

GitHub Actions runs Ruff, pytest, and example-manifest validation on pushes to `main` and pull requests targeting `main`.

## Local checks

```bash
pip install -e ".[dev]"
ruff check .
pytest -q
vulnresearch validate examples/task.json
```
